# FontMemo

> 好きなフォントで、好きな言葉を。

お気に入りのフォントで書いた言葉は、ただのメモじゃなくなる。
日記のひとこと、大切な人へのメッセージ、手帳に貼る小さなラベル。
FontMemoは、好きなフォントで文章を書いて、サーマルプリンタで印刷できる画像にするための小さなWebアプリです。

※ 現在開発中です。公開したら、ここにWebアプリのURLを載せます。

## こんな困りごと、ありませんか

プリンタのアプリに、使いたいフォントがない。
だから別のアプリで文章を書いて、スクリーンショットを撮って、画像として印刷してた。
でも、文章が長いと画面に入りきらない……。

FontMemoなら、文章をそのまま入力するだけ。
長くても、全部が1枚の画像になります。

## できること

- **フォントを自由に取り込める** — FONT FREE などで配布されているフリーフォント（TTF / OTF）を読み込んで、そのまま使えます。取り込んだフォントは端末に保存されるので、次回からは選ぶだけ
- **長い文章も1枚に** — 印刷幅で自動的に折り返して、縦に長い1枚のPNGにします。スクリーンショットはもう要りません
- **横印刷モード** — 文字を90度回転させて、紙送りの方向に長く伸びる、バナーやリボンのような印刷もできます
- **プリンタ幅ぴったり** — 384px（200dpi相当、T02など）／576px（300dpi相当、M02Sなど）の幅でそのまま描くので、縮小で文字がぼやけません。幅のカスタム指定もできます
- **印刷向けに二値化** — サーマルプリンタできれいに刷れるよう、文字をくっきりと黒と白に変換します
- **選んだフォントに無い文字はお知らせ** — その文字だけ別の書体になる場合は、プレビューで目印と警告が出ます。知らないうちに化けていた、ということがありません
- **オフラインでも使える** — PWAとしてホーム画面に追加できます。文章やフォントをサーバーに送ることはありません
- **無料・登録なし・広告なし**

## 使い方

1. フォントを取り込む（配布サイトでダウンロードしたフォントファイルを選ぶだけ）
2. 文章を書いて、フォントと文字の大きさを選ぶ
3. プレビューで確認して、PNGを保存する
4. いつものプリンタアプリ（Phomemoアプリなど）から画像印刷する

## フォントについて

FontMemoにフォントは同梱されていません。使いたいフォントは、配布サイトからご自身でダウンロードして取り込む形です。
各フォントのライセンス（商用利用の可否など）は、それぞれの配布元の規約に従ってください。

## 対応について

- 印刷は、PNG画像を読み込めるプリンタアプリ経由で行います（FontMemo自体はプリンタと通信しません）
- 想定プリンタ：Phomemo T02、M02S など
